# TAT Agency System

نظام داخلي لـ TAT Agency لإدارة العملاء والعقود، الفواتير والمصاريف، والتحصيل والمدفوعات — بواجهة عربية (RTL) وباك إند حقيقي وقاعدة بيانات PostgreSQL، يشتغل بالكامل عبر Docker.

## المكوّنات

- **frontend/** — واجهة React (Vite)، بتتصل بالباك إند عبر `/api`.
- **backend/** — Node.js + Express + PostgreSQL، مع تسجيل دخول (JWT) لكل عضو في الفريق.
- **database/** — ملف `schema.sql` اللي بيبني كل الجداول أول ما الباك إند يشتغل.

### الموديولات المتاحة حاليًا
1. **العملاء** — بيانات العقود، القيمة (جنيه مصري)، دورة التجديد (شهري/ربع سنوي/سنوي)، وتحليل شهري.
2. **الفواتير والمصاريف** — تتبّع الإيرادات والمصاريف وصافي الربح، مع **فوترة تلقائية شهرية** وتصدير كل فاتورة كـ **PDF براند TAT** بالعربي وباللوجو الحقيقي.
3. **التحصيل والمدفوعات** (صفحة واحدة) — حالة دفع كل فاتورة وأعمار الديون، مع لوحة تحصيل ومتابعات وتقرير أداء لمديري الحسابات. أي فاتورة صادرة وعليها رصيد بيتعملها سجل تحصيل أوتوماتيك، وبيتأكد سداده لما تتدفع.
4. **إعلانات العملاء** — تتبّع ميزانيات الإعلانات المستلمة من العملاء: النظام بيحسب أوتوماتيك عمولة الوكالة (20% افتراضيًا، قابلة للتعديل لكل عملية) والصافي اللي بيروح للحساب الإعلاني، مع تحليل حسب العميل والمنصة والشهر. **عمولة الوكالة بتتحسب ضمن دخل وأرباح الشركة** (صافي الربح = المحصّل من الفواتير + عمولة الإعلانات − المصاريف).

**ملحوظة**: النظام بيشتغل بعملة واحدة بس (جنيه مصري) في كل الموديولات.

### الفوترة التلقائية الشهرية
كل أول شهر (الساعة 00:05 بتوقيت الحاوية) النظام بيعمل أوتوماتيك فاتورة "مرسلة" لكل عميل نشط حسب دورة تجديده:
- **شهري** → فاتورة كل شهر.
- **ربع سنوي** → فاتورة كل 3 شهور بس (مش كل شهر).
- **سنوي** → فاتورة كل 12 شهر بس.
- **مرة واحدة** → مالوش فوترة تلقائية خالص.

آمن يتكرر — لو شغّلته أكتر من مرة في نفس الشهر، مش هيعمل فاتورة مكررة لنفس العميل. تقدر كمان تشغّله يدويًا في أي وقت من زرار "توليد فواتير هذا الشهر" في صفحة الفواتير (متاح للأدمن بس).

### فواتير PDF
كل فاتورة (تلقائية أو يدوية) ليها زرار "PDF" بيولّد ملف فاتورة رسمي بتصميم TAT (نيفي/ذهبي/تيل) بالعربي RTL، بخط Tajawal مضمّن بالكامل جوه الملف (مش محتاج إنترنت وقت التوليد)، وباللوجو الحقيقي بتاع TAT Agency.

## التشغيل (بالكامل عبر Docker)

### المتطلبات
- [Docker](https://docs.docker.com/get-docker/) و Docker Compose مثبتين على جهازك أو السيرفر.

### الخطوات

1. **انسخ ملف البيئة:**
   ```bash
   cp .env.example .env
   ```
2. **افتح `.env` وغيّر القيم دي على الأقل:**
   - `DB_PASSWORD`
   - `JWT_SECRET` (استخدم قيمة عشوائية طويلة، مثلاً: `openssl rand -base64 48`)
   - `ADMIN_EMAIL` و `ADMIN_PASSWORD` (حساب المدير الأول اللي هتسجل بيه أول مرة)

3. **شغّل كل حاجة:**
   ```bash
   docker-compose up --build
   ```
   أول مرة هياخد شوية وقت (بناء الصور + تثبيت الحزم). المرات الجاية هتكون أسرع.

4. **افتح المتصفح على:**
   ```
   http://localhost:8080
   ```
   (أو الرقم اللي حطيته في `FRONTEND_PORT` لو غيّرته)

5. **سجّل الدخول بالحساب اللي حددته في `.env`** (`ADMIN_EMAIL` / `ADMIN_PASSWORD`).

### تشغيل في الخلفية
```bash
docker-compose up -d --build
```

### إيقاف النظام
```bash
docker-compose down
```
(البيانات بتفضل محفوظة في volume اسمه `tat_pgdata` حتى لو أوقفت الحاويات. لو عايز تمسح البيانات كمان: `docker-compose down -v`)

## الإعدادات (صفحة «الإعدادات»)
- **الملف الشخصي:** الاسم والهاتف والإيميل (تغيير الإيميل بيطلب كلمة المرور الحالية) وصورة شخصية.
- **الأمان:** تغيير كلمة المرور (بتقفل الدخول من باقي الأجهزة) وتسجيل الخروج من كل الأجهزة وآخر دخول.
- **التفضيلات:** الوضع الداكن/الفاتح، شكل القائمة الجانبية، الفلاتر الافتراضية وصفحة البداية — بتتحفظ على الحساب وبتتبعك على أي جهاز.
- **إعدادات الشركة (للمدير):** الاسم والشعار النصي واللوجو وبيانات التواصل والرقم الضريبي، ونسبة عمولة الإعلانات الافتراضية، وبادئة ترقيم الفواتير، ونص أسفل الفاتورة (بيظهر في الـ PDF). العملة ثابتة EGP.

## إضافة أعضاء جدد للفريق

كل عضو في الفريق لازم يبقى عنده حساب منفصل (إيميل + باسورد). دلوقتي الطريقة المتاحة لإضافة عضو جديد هي عبر الـ API مباشرة (لسه مفيش شاشة "إدارة الفريق" جوه الواجهة — ينفع نضيفها في تطوير لاحق):

```bash
curl -X POST http://localhost:8080/api/auth/users \
  -H "Authorization: Bearer <TOKEN_بتاع_الأدمن>" \
  -H "Content-Type: application/json" \
  -d '{"name":"اسم الموظف","email":"employee@tatagency.com","password":"كلمة_مرور_قوية","role":"member"}'
```

للحصول على `<TOKEN_بتاع_الأدمن>`: سجّل دخول عادي من الواجهة، وافتح Developer Tools في المتصفح → Application/Storage → Local Storage → انسخ قيمة `tat_token`.

├── frontend/           # React + Vite + nginx (للإنتاج)
├── backend/
│   ├── src/
│   │   ├── routes/     # عملاء، فواتير، مصاريف، تحصيل

│   │   ├── pdf/          # توليد فواتير PDF (خط Tajawal مضمّن)

├── .env.example

## ملاحظات مهمة

- **الباك إند بيعمل migrate تلقائي** (بيطبّق `schema.sql` ويزرع حساب الأدمن الأول) في كل مرة الحاوية بتشتغل — آمن يتكرر، مش هيمسح بيانات موجودة.
- **كل الأرقام بعملة واحدة في كل تقرير** (تختارها من القايمة المنسدلة أعلى الصفحة) عشان مايحصلش خلط بين ريال وجنيه ودولار.
- لو حابب تضيف موديولات تانية اتعملت قبل كده كـ Artifacts منفصلة (زي تقويم المحتوى، Onboarding، تتبع المنافسين) جوه نفس النظام ده، قول وهنكمل عليه.

## تطوير محلي (بدون Docker)

لو عايز تشتغل على الكود مباشرة من غير Docker (يحتاج Node.js 20+ و PostgreSQL مثبتين محليًا):

```bash
# الباك إند
cd backend
npm install
# اضبط متغيرات البيئة (DB_HOST=localhost إلخ) أو استخدم ملف .env
npm run migrate   # يبني الجداول ويزرع حساب الأدمن
npm run dev

# الفرونت إند (في تيرمنال تاني)
cd frontend
npm install
npm run dev
```
